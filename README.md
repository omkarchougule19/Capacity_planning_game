Last Mile Command
An interactive capacity planning simulation for operations strategy education.
Grounded in published truck-and-drone last-mile delivery research, the game puts players in charge of a logistics network — making fleet, infrastructure, and outsourcing decisions across multiple quarters while responding to random market disruptions.

Running Locally
bash pip install flask flask-cors numpy
python app.py
Then open http://localhost:5000.

Stack
Python · Flask · Vanilla JS · Chart.js

Academic Context
Intended as an educational tool for operations strategy coursework.
